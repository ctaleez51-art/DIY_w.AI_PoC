# 말로 장부 작성하기

개인사업자 간편장부에 **말로** 한 줄씩 넣는다.

> "어제 다이소에서 사무용품 3만원어치 샀어"
> → ①일자 `2026-09-25` ②계정과목 `소모품비` ③거래내용 `사무용품` ④거래처 `다이소` ⑥비용금액 `30000`

컴퓨터가 어렵거나 나이가 많아서 파일 올리기·직접 입력이 힘든 사람이
**스스로 자기 장부를 쓰게 하는 것**이 목적이다.

- 과제: 아이펠 PoC — 내 도메인(세무)에 AI 를 넣어 나아지는 것을 증명한다
- 문제 정의서: [`문제정의서.md`](문제정의서.md)
- 모델을 왜 이것으로 골랐나: [`모델선정근거.md`](모델선정근거.md)
- 얼마나 나아졌나: [`검증.md`](검증.md)

## 어떻게 도는가

AI 가 두 군데에서 돈다. **받아적기만 코랩(GPU)이고, 칸 나누기는 내 컴퓨터다.**

```
        🎤 브라우저 (내 컴퓨터)
             │
   ①소리 ────┼──────────────▶  코랩 GPU — Whisper small
             │                        │
             │◀──────②글자───────────┘
             │
   ③글자 ────┼──────────────▶  내 컴퓨터 Ollama — gemma3:4b
             │                        │
             │◀──────④장부 칸────────┘
             ▼
     장부 표에 한 줄 → [저장] → Supabase
```

**왜 나눴나** — 젬마는 내 컴퓨터에 이미 깔려 있다. 코랩에 또 깔 이유가 없다.
그리고 이렇게 하면 **장부 내용이 내 컴퓨터 밖으로 나가지 않는다.** 코랩에는 소리만 간다.

앞 과제(`DIY_w.AI`)에서 만든 간편장부 사이트를 **그대로 이어받아** 🎤 만 붙였다.

## 실행 방법

### 1. 코랩에서 받아적기 서버를 켠다

1. [`colab.ipynb`](colab.ipynb) 를 [코랩](https://colab.research.google.com/)에 올린다
2. **런타임 → 런타임 유형 변경 → T4 GPU**
3. **런타임 → 모두 실행**
4. 맨 아래 칸이 주소를 찍어준다 — `https://○○○.trycloudflare.com`

> GPU 를 못 잡으면 CPU 로 그냥 돈다. 코드는 하나다. 느릴 뿐이다.
> 노트북을 닫으면 주소는 사라진다. 다시 켜면 주소가 바뀐다.

### 2. 내 컴퓨터에서 젬마가 떠 있는지 본다

```powershell
ollama list
```

`gemma3:4b` 가 보이면 된다. 없으면:

```powershell
ollama pull gemma3:4b
```

### 3. 사이트를 연다

```powershell
cd C:\Users\ctale\Desktop\claudecode\DIY_w.AI_PoC
python -m http.server 8080
```

크롬에서 `http://localhost:8080`

### 4. 말한다

1. 로그인 → 개인정보·사업장 등록 → 사업장을 **고른다**
2. `받아적기 주소` 칸에 1번에서 받은 코랩 주소를 붙여넣는다 (한 번 넣으면 기억한다)
3. `젬마 주소` 는 `http://127.0.0.1:11434` 그대로 둔다
4. **🎤 말하기** → 거래 한 건을 말한다 → **■ 다 말했어요**
5. 장부 표에 한 줄이 생긴다 → **저장**

### 안 될 때

| 증상 | 까닭 |
|---|---|
| 마이크가 안 켜진다 | `file://` 로 열면 안 된다. 위 3번처럼 `localhost` 로 열어야 한다 |
| "받아적기 서버에 닿지 않습니다" | 코랩 런타임이 끊겼다. 다시 실행하고 새 주소를 넣는다 |
| "젬마에 닿지 않습니다" | Ollama 가 꺼져 있다. 켜고 다시 해본다 |
| 젬마 쪽에서 CORS 오류 | 파워셸에서 `setx OLLAMA_ORIGINS "*"` 한 번 하고 Ollama 를 껐다 켠다 |

## 정한 규칙

| 항목 | 규칙 |
|---|---|
| 수입/비용 가르기 | 판 것·받은 것은 **수입**, 산 것·낸 것은 **비용**, 차·기계처럼 오래 쓰는 것은 **자산** |
| 금액 | **부가세를 뺀 금액.** 총액과 부가세를 같이 말하면 빼서 넣는다 |
| 부가세 | **말했을 때만** 넣는다. 멋대로 10% 를 떼지 않는다 |
| 날짜 | "어제", "3월 5일" 을 오늘 기준으로 계산해 `2026-09-25` 모양으로 |
| 꼭 있어야 하는 칸 | **일자 · 거래내용 · 금액.** 하나라도 없으면 **장부에 넣지 않고** 다시 말하게 한다 |
| 비고 | 말로 넣은 줄은 `말` 로 적는다 |
| 말하는 순서 | 없다. 아무렇게나 말해도 젬마가 나눈다 |
