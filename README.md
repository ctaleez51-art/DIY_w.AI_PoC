# 간편장부 (DIY_w.AI)

개인사업자가 종합소득세 신고용 **간편장부를 스스로 작성**할 수 있게 도와주는 웹 서비스.

**실행 주소 — https://ctaleez51-art.github.io/DIY_w.AI/**

## 무엇을 하는가

수동 입력은 품이 들고, 스크래핑은 틀린 값을 받는다. 그 사이로 간다 —
**사용자가 가진 파일을 그대로 읽어서 국세청 간편장부 서식에 맞춰준다.**

```
파일 업로드 → 간편장부 서식에 자동 매핑 → 연도 거르기 → 저장 → 조회
```

## 읽는 파일

| 파일 | 형식 |
|---|---|
| 매출 전자세금계산서 목록 | `xlsx` · `xls` · `csv` |
| 매입 전자세금계산서 목록 | `xlsx` · `xls` · `csv` |

- 여러 개를 한 번에 올릴 수 있다. 표가 몇 행부터 시작하든 머리글을 찾아서 읽는다
- 매출인지 매입인지는 파일명이 아니라 **사업자등록번호로** 가린다
- 장부는 오래된 날짜부터 놓인다

## 기능

- 이메일 로그인 / 회원가입
- 개인정보 등록 (종합소득세 신고서 인적사항 10개 칸)
- 사업장 등록 · 목록 · 고르기 · 수정 · 삭제 (여러 개 등록 가능)
- 파일 업로드 → 간편장부 8개 항목으로 매핑
- 기준 연도가 아닌 줄 골라내기 (앱이 알아서 빼지 않는다. 확인을 눌러야 빠진다)
- 사업장별로 장부 저장 · 조회

## 쓴 것
