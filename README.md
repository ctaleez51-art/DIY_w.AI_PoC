# 말로 장부 작성하기

개인사업자 간편장부에 **말로** 한 줄씩 넣는다.

> "어제 다이소에서 사무용품 3만원어치 샀어"
> → ①일자 `2026-09-25` ②계정과목 `소모품비` ③거래내용 `사무용품` ④거래처 `다이소` ⑥비용금액 `30000`

컴퓨터가 어렵거나 나이가 많아서 파일 올리기·직접 입력이 힘든 사람이
**스스로 자기 장부를 쓰게 하는 것**이 목적이다.

- 과제: 아이펠 PoC — 내 도메인(세무)에 AI 를 넣어 나아지는 것을 증명한다
- 문제 정의서: [`문제정의서.md`](문제정의서.md)
- 모델을 왜 이것으로 골랐나: [`모델선정근거.md`](모델선정근거.md)
- 얼마나 나아졌나: [`검증.md`](검증.md)

## 어떻게 도는가

```
🎤 브라우저 녹음
      │  소리 (webm)
      ▼
코랩 노트북 (GPU)
   Whisper  ── 받아적기 ──▶  "어제 다이소에서 사무용품 3만원어치 샀어"
      │
   젬마 3:4b (Ollama, 바깥 API 안 씀)
      │  칸 나누기
      ▼
  간편장부 8개 항목 JSON
      │
      ▼
사이트가 장부 표에 한 줄 추가 → [저장] → Supabase
```

- 앞 과제(`DIY_w.AI`)에서 만든 간편장부 사이트를 **그대로 이어받아** 🎤 만 붙였다
- 코랩과 브라우저는 `cloudflared` 임시 터널로 잇는다. 가입도 키도 필요 없다

## 실행 방법

### 1. 코랩에서 AI 서버를 켠다

1. [`colab.ipynb`](colab.ipynb) 를 [코랩](https://colab.research.google.com/)에 올린다
2. **런타임 → 런타임 유형 변경 → T4 GPU**
3. 위에서부터 **모든 칸을 차례대로 실행**한다 (젬마 내려받는 데 몇 분 걸린다)
4. 맨 아래 칸이 주소를 하나 찍어준다 — `https://○○○.trycloudflare.com`

> GPU 를 못 잡으면 CPU 로 그냥 돈다. 코드는 하나다. 느릴 뿐이다.
> 노트북을 닫으면 주소는 사라진다. 다시 켜면 주소가 바뀐다.

### 2. 사이트를 연다

```bash
python -m http.server 8080
```

브라우저에서 `http://localhost:8080` 을 연다.
(배포본은 앞 과제 주소가 아니라 이 저장소의 것을 따로 올려야 한다)

### 3. 말한다

1. 로그인 → 개인정보·사업장 등록 → 사업장을 **고른다**
2. `AI 주소` 칸에 1번에서 받은 주소를 붙여넣는다 (한 번 넣으면 기억한다)
3. **🎤 말하기** 를 누르고 거래 한 건을 말한다
4. **■ 다 말했어요** 를 누른다
5. 장부 표에 한 줄이 생긴다 → **저장**

### 마이크가 안 켜질 때

브라우저는 `localhost` 나 `https` 에서만 마이크를 내준다.
`index.html` 을 파일로 바로 열면(`file://`) 마이크가 안 된다. 위 2번처럼 서버로 열어야 한다.

## 정한 규칙

| 항목 | 규칙 |
|---|---|
| 수입/비용 가르기 | 판 것·받은 것은 **수입**, 산 것·낸 것은 **비용**, 차량·기계처럼 오래 쓰는 것은 **자산** |
| 부가세 | **말했을 때만** 넣는다. 멋대로 10% 를 떼지 않는다 |
| 날짜 | "어제", "3월 5일" 을 오늘 기준으로 계산해 `2026-09-25` 모양으로 |
| 꼭 있어야 하는 칸 | **일자 · 거래내용 · 금액.** 하나라도 없으면 **장부에 넣지 않고** 빠졌다고 알려준다 |
| 비고 | 말로 넣은 줄은 `말` 로 적는다 |
| 말하는 순서 | 없다. 아무렇게나 말해도 젬마가 나눈다 |
