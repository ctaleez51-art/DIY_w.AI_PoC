# 말로 장부 작성하기

개인사업자 간편장부에 **말로** 한 줄씩 넣는다.

> "어제 다이소에서 사무용품 3만원어치 샀어"
> → ①일자 `2026-09-25` ③거래내용 `사무용품` ④거래처 `다이소` ⑥비용금액 `30000`

컴퓨터가 어려워서 파일 올리기·직접 입력이 힘든 사람이
**스스로 자기 장부를 쓰게 하는 것**이 목적이다.

- 과제: 아이펠 PoC — 내 도메인(세무)에 AI 를 넣어 나아지는 것을 증명한다
- 문제 정의서: [`문제정의서.md`](문제정의서.md)
- 모델을 왜 이것으로 골랐나: [`모델선정근거.md`](모델선정근거.md)
- 얼마나 나아졌나: [`검증.md`](검증.md)

## 어떻게 도는가

**AI 두 개가 모두 내 컴퓨터 안에서 돈다.** 밖으로 나가는 것은 저장할 장부 줄뿐이다.

```
        🎤 브라우저
             │
   ①소리 ────┼──────────────▶  받아적기.py — Whisper small (CPU)
             │                        │
             │◀──────②글자───────────┘
             │
   ③글자 ────┼──────────────▶  Ollama — gemma3:4b (CPU)
             │                        │
             │◀──────④장부 칸────────┘
             ▼
     장부 표에 한 줄 → [저장] → Supabase
```

**밖에 맡기지 않는 이유** — 말소리에는 거래처와 금액이 들어 있다. 남의 장부다.
그리고 빌린 GPU 는 돈이 들고, 켤 때마다 주소가 바뀌어 **쓰는 사람이 주소를 붙여넣어야 했다.**
둘 다 없앴다. 지금은 주소를 물어보지 않는다.

**GPU 는 쓰지 않는다.** 노트북에 GPU 가 없다. CPU 로 돈다.

앞 과제(`DIY_w.AI`)에서 만든 간편장부 사이트를 **그대로 이어받아** 🎤 만 붙였다.

## 실행 방법

### 1. 처음 한 번만

```powershell
pip install faster-whisper
ollama pull gemma3:4b
```

### 2. 받아적기를 켠다

```powershell
cd C:\Users\ctale\Desktop\claudecode\DIY_w.AI_PoC
python 받아적기.py
```

`준비됐습니다.` 가 뜨면 된다. 처음 켤 때는 Whisper 모델(484MB)을 받느라 몇 분 걸린다.
**창을 닫지 말고 그대로 둔다.**

### 3. 사이트를 연다 — 창을 하나 더 열어서

```powershell
cd C:\Users\ctale\Desktop\claudecode\DIY_w.AI_PoC
python -m http.server 8080
```

크롬에서 `http://localhost:8080`

### 4. 말한다

1. 로그인 → 개인정보·사업장 등록 → 사업장을 **고른다** → `장부보기`
2. **🎤 말하기** → 거래 한 건을 말한다 → **■ 다 말했어요**
3. 장부 표에 한 줄이 생긴다
4. 여러 건 말한 뒤 마지막에 **저장** 을 한 번 누른다

붙여넣을 주소는 없다. 두 서버 모두 `127.0.0.1` 로 고정이라 코드에 적혀 있다.

### 안 될 때

| 증상 | 까닭 |
|---|---|
| 마이크가 안 켜진다 | `file://` 로 열면 안 된다. 위 3번처럼 `localhost` 로 열어야 한다 |
| "받아적기가 켜져 있지 않습니다" | 2번의 `받아적기.py` 창이 닫혔다. 다시 켠다 |
| "젬마가 켜져 있지 않습니다" | Ollama 가 꺼져 있다. 켜고 다시 해본다 |
| 젬마 쪽에서 CORS 오류 | 파워셸에서 `setx OLLAMA_ORIGINS "*"` 한 번 하고 Ollama 를 껐다 켠다 |

## 정한 규칙

| 항목 | 규칙 |
|---|---|
| 수입/비용 가르기 | 판 것·받은 것은 **수입**, 산 것·낸 것은 **비용**, 차·기계처럼 오래 쓰는 것은 **자산** |
| 계정과목 | **젬마가 고르지 않는다.** 서식의 칸은 두고 비워둔다. 세무 판단이라 사람이 넣는다 |
| 금액 | 총액과 부가세를 **같이 말했을 때만** 빼서 넣는다. 안 나눠 말하면 말한 금액이 그대로 들어간다 |
| 부가세 | **말했을 때만** 넣는다. 멋대로 10% 를 떼지 않는다 |
| 날짜 | "어제", "3월 5일" 을 오늘 기준으로 계산해 `2026-09-25` 모양으로 |
| 꼭 있어야 하는 칸 | **일자 · 거래내용 · 금액.** 하나라도 없으면 **장부에 넣지 않고** 다시 말하게 한다 |
| 비고 | 말로 넣은 줄은 `음성` 으로 적는다 |
| 말하는 순서 | 없다. 아무렇게나 말해도 젬마가 나눈다 |
